# [실습 자료] 신규 제안 브리프 — 커머스 A사 (가상)

> 교육용 가상 브리프입니다. 실제 광고주 정보가 아닙니다.
> 정보가 일부러 비어 있습니다. 무엇이 비어 있는지 찾아내는 것도 실습의 일부입니다.

## 1. 기본 정보

- 광고주: 커머스 A사 (가상)
- 업종: 종합 이커머스 앱
- 제안 형태: 경쟁 제안 (당사 포함 3개 대행사)
- 발표: 20분 발표 + 10분 Q&A
- 참석자: 마케팅 총괄 임원, 퍼포먼스 팀장, 데이터 분석 담당

## 2. 광고주가 보낸 요청사항 (원문 요약)

1. 신규 설치 확보와 첫 구매 전환을 동시에 개선하고 싶다.
2. 지금은 매체별 성과를 각각 보고받고 있어 전체 그림이 안 보인다.
3. 리포트에 숫자는 많은데 "그래서 무엇을 해야 하는지"가 없다.
4. iOS 성과 해석을 신뢰하기 어렵다는 내부 의견이 있다.
5. 크리에이티브 제작 속도가 느려 소재 교체 주기가 길다.

## 3. 현재 상황 (광고주 제공)

| 항목 | 내용 |
| --- | --- |
| 월 광고비 | 약 1억 5천만 원 |
| 운영 매체 | Meta, Google, TikTok, 네이버 GFA |
| 현재 CPA | 첫 구매 기준 약 14,000원 |
| 목표 CPA | 12,000원 이하 |
| 앱 설치 후 첫 구매 전환율 | 약 6% |
| 소재 교체 주기 | 3~4주 |
| MMP | 사용 중 (도구명 미공개) |
| 내부 인력 | 마케팅 4명 (데이터 전담 없음) |

## 4. 경쟁 상황

- 동일 카테고리 경쟁사 3곳이 유사한 메시지(가격·배송 속도)로 집행 중.
- 경쟁사 소재 관찰 결과는 `M5_02_경쟁사_소재_수집표.csv` 참고.
- 광고주는 "가격 경쟁으로는 이기기 어렵다"는 인식을 갖고 있음.

## 5. 제약 조건

- 광고비 증액은 당분간 불가. 같은 예산으로 개선해야 한다.
- 신규 제작 인력 채용 계획 없음. 제작 리소스는 대행사가 부담.
- 개인정보 관련 내부 심의로 데이터 반출 범위에 제한이 있음(범위 미확정).
- 계약 시작 희망 시점: 다음 분기 첫 달.

## 6. 브리프에 없는 것 (제안 전 확인 필요)

- 목표 CPA 12,000원의 근거와 산출 방식
- 재구매율·LTV 데이터 제공 가능 여부
- 현재 리포트에서 가장 불만족스러운 부분의 구체적 예시
- iOS 성과 해석 불신의 구체적 계기
- 심의로 제한되는 데이터 항목의 목록
- 의사결정 기준과 최종 결정권자
