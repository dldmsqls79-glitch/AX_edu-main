# public/images — 웹 디자인용 이미지

`/images/…` 로 접근됩니다. 예: `public/images/hero/ax-cover.webp` → `/images/hero/ax-cover.webp`

## 폴더 구분

| 폴더 | 용도 | 권장 규격 |
| --- | --- | --- |
| `hero/` | 페이지 상단 배경·일러스트 | 가로 2400px 이상, `webp` |
| `card/` | 카드·목록 썸네일 | 가로 1200px, 4:3 또는 16:9, `webp` |
| `illust/` | 아이콘보다 큰 설명용 그림·다이어그램 | 가능하면 `svg` |
| `og/` | 공유 미리보기(og:image) | **1200 × 630 고정**, `png` |

브랜드 로고는 이 폴더가 아니라 [`public/brand/`](../brand/README.md) 입니다.

## 넣을 때 확인할 것

1. **파일명은 소문자 + 하이픈**, 내용을 알 수 있게. 한글·공백 금지.
   `hero/session-2-prompt.webp` (○) / `hero/이미지 1.png` (×)
2. **사진·스크린샷은 `webp`** (같은 화질에 용량 1/3), **도형·다이어그램은 `svg`**.
   투명이 필요한 래스터는 `png`.
3. **레티나 대응은 2배 크기 한 장**으로 충분합니다. 표시할 크기의 2배로 넣어주세요.
   `@2x` 접미사가 있으면 그 뜻으로 읽습니다.
4. **한 장이 500KB를 넘지 않게** 해주세요. 넘으면 알려주시면 압축해서 넣겠습니다.
5. 스크린샷에 **광고주 실명·계정·실제 성과 수치가 보이지 않게** 확인해 주세요.
   교육용 자료는 전부 가상 데이터 기준으로 만들었습니다.

## 사용 방식

이 프로젝트는 `next/image` 대신 대부분 일반 `<img>` 를 씁니다(정적 프리렌더 + 외부 호스트 없음).
큰 히어로 이미지가 들어오면 해당 위치만 `next/image` 로 바꿔 자동 리사이즈·지연 로딩을 붙이겠습니다.
