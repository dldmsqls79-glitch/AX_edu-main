# 데이터 기반 풀스택 마케팅 솔루션 기획서 (상세)

**HSAD × Wisebirds | AI 솔루션 공동 개발 기획(안)** · 2026. 08

광고 프로세스 전 단계(시장 분석 → 타겟 도출 → 데이터 분석 → 크리에이티브 제작)를 AI로 자동화·간편화하는 퍼포먼스 브랜딩 솔루션 프레임워크

## 1. 기획 배경 및 차별화 방향

### 1-1. 기존 퍼포먼스 대행사 제안과의 차별점

| 구분 | 기존 퍼포먼스 대행사 | 본 솔루션 (퍼포먼스 브랜딩) |
|---|---|---|
| 제안 출발점 | 매체 포트폴리오 다각화, 정교한 타겟팅 셋팅, ROAS 시뮬레이션 표 | '퍼포먼스 브랜딩'으로 제안의 출발점과 끝점 자체를 다르게 설계 |
| 관점 | "구글 PMax를 잘 쓴다", "메타 셋팅 노하우가 있다" 등 매체 최적화 기법 중심 | 매체 최적화는 AI가 하는 것. **진짜 차별화는 AI에게 입력하는 인풋의 퀄리티**에서 나온다는 논리 — AI 학습 효율을 극대화하는 크리에이티브 에셋 공급 체계로 AI를 리드하는 전략가 포지셔닝 |
| 핵심 솔루션 | 매체 믹스 조정, 매체별 입찰 전략 변경, 소재 A/B 테스트 | 뎁스 있는 소비자 인사이트(인텐트릭스, 실시간 소셜 크롤링)에서 출발한 확장성 있는 메시지 체계 설계 + 브랜드 핵심 자산(Identity)을 관통하는 킬러 크리에이티브 + CDJ 풀퍼널 자동 매핑 |
| 타겟 접근 | 단순 타겟팅 세분화 | CDJ 풀코스 설계도를 시각화하여 제안 — "어디서 고객을 더 데려올 것인가"가 아니라 **"광고주 마케팅 퍼널 상에서 어디서 돈이 새고 있는가"를 진단** |
| 소재 전략 | 할인·혜택 중심의 단발성 이미지/숏폼 대량 양산 | 브랜드 가치를 훼손하지 않으면서 높은 전환을 유도하는 '일관성 있는 크리에이티브 시스템' — 브랜드 에센스/비주얼 가이드를 명확히 세우고, 이를 기반으로 빠르게 변형 가능한 **모듈형 크리에이티브 시스템** |
| 최종 KPI | 단기 대시보드상의 ROAS 수치 향상 | **단기 ROAS 개선 + 장기 브랜드 체력 지수 동시 제고** — 단기 성과와 지속가능한 성장을 동시에 잡는 파트너 |

### 1-2. 현재 퍼포먼스 마케팅의 페인포인트와 보완 솔루션

| # | 페인포인트 | 보완 솔루션 | CDJ 연계 |
|---|---|---|---|
| 1 | AI 자동화 캠페인은 효율은 극대화하지만 흐름을 알 수 없는 **블랙박스 구조** — 특정 타겟에서 왜 반응이 나오는지 원인 분석 불가, AI가 어떤 지면에 누구에게 왜 예산을 썼는지 세부 데이터 파악 불가 | **AI 의도 역추적 알고리즘 분석** (AI가 특정 타겟에게 예산을 몰아준 이유 분석) + **브랜드 가이드라인 맞춤 스마트 Safe 기능** (브랜드에 맞지 않는 매체 지면 노출 완전 통제) | 브랜드 탐색·비교 단계 — 일관된 메시지와 안전한 이미지 전달 |
| 2 | 쿠키 제한 등으로 광고비가 진짜 매출로 연결됐는지 **증명이 어려움** — 기여도를 마지막 검색광고가 독식하는 구조로, 브랜딩 기여 가치의 정량 입증이 까다로움 | **소비자의 모든 터치포인트 데이터를 추적하는 솔루션** — 유저 흐름 트래킹으로 라스트 클릭뿐 아니라 초기 접점부터 기여도를 정확히 배분, 초기 고려 단계 활동(브랜딩 광고)이 실제 구매 순간에 미친 영향을 유기적으로 연결·증명 | 초기 고려 → 구매 순간 |
| 3 | **크리에이티브 피로도 가속화와 리소스 제약** — 타겟팅 자동화로 동일 타겟 노출 빈도가 빨라져 소재 피로도가 높아지고 효율 급락. 퍼포먼스 광고의 승패가 '소재'에서 갈리는 시대 | **크리에이티브 시뮬레이터** (미디어 리포트 연동 대시보드에서 소재 시각화, 반응률 임계점 하락 시 교체 알람, AI가 브랜드 가이드북 기반으로 카피·비주얼 자동 변형해 소재 세트 대기) + **모듈형 에셋** | 대안 비교·탐색 단계 — 소재 피로도를 낮추고 새 크리에이티브로 이탈 방지 |
| 4 | 단기 성과에 집착하면 **브랜드 체력 저하** — 시장 파이를 키우지 않고 타겟팅 광고만 돌리면 한정된 모수 안에서 경쟁해 고객 획득 비용만 상승 | **브랜드 체력 지수 모니터** — 자발적 검색량 추이, 소셜 바이럴 추천 지수, 팬덤 지수를 함께 분석하는 실시간 대시보드 (예: 단기 매출은 늘었으나 체력 지수가 깎이면 알람) | Post Purchase — 평가 단계를 건너뛰고 재구매하는 로열티 루프 형성 유도·모니터링 |

## 3. HSAD 기존 솔루션 활용 영역

### A. 시장 분석

> 트렌드·이슈 리서치를 자동화해 시장을 파악하는 시간을 대폭 단축

#### A-1. 실시간 트렌드 모니터링

1) **검색 트렌드 API 활용 신호 통합** — 구글 트렌드·네이버 데이터랩 등 검색 트렌드 API로 검색량 급상승 감지, 날씨 API(기온·강수·미세먼지 등 예측 가능한 신호)까지 실시간 신호 소스로 통합
2) **검색 급상승에 따른 소셜·커뮤니티 크롤링** — 소셜 리스닝 데이터로 언급량이 갑자기 늘어난 키워드 포착, 여행 커뮤니티·SNS 실시간 VOC 등 업종별 커뮤니티 크롤링
3) **경쟁사 광고 실시간 수집** — 경쟁사 최신 집행 데이터를 함께 분석하여, 비슷한 소재만 반복적으로 뽑히는 문제점 해소

#### A-2. 신호 처리·매핑

1) **변화율 계산 및 임계치 기반 1차 필터링** — 각 신호 소스를 주기적으로(예: 시간 단위) 크롤링·조회해 전일·전주 대비 변화율 계산 → 임계치(예: 검색량 전일 대비 200% 이상 증가)를 넘는 키워드를 '급상승 후보'로 1차 필터링
2) **신호–업종/브랜드 매핑 테이블** — 어떤 외부 신호가 어떤 업종/브랜드와 연관 있는지 정의해 둔 규칙·데이터 (예: "폭염" → 아이스크림/음료/여행(계곡·바다), "장마" → 배달/실내 여가). 데이터가 쌓이면 임베딩 유사도 매칭으로 고도화 가능
3) **업종별 시장 동향 리포트 자동 생성** — 검색 급상승·소셜 이슈·경쟁사 광고를 실시간 수집해 업종별 시장 동향 리포트를 자동 생성

#### A-3. 소비자 인사이트 추출

1) **인텐트릭스(INTENTrix) 기반 심리·페인포인트 분석** — 500~1,000명 모수 대상 소비자 인사이트 추출. 세대별 여가/여행 행동 유발 심리, 경기 불황기 소비 심리 위축 요인 등 브랜드별 맞춤 분석
2) **소비자 VOC·인텐트 크롤링** — 소비자 지출 관련 VOC, 여행에 대한 VOC 등 소비자 의도 데이터 크롤링. 퍼포먼스 소재의 중간 포인트 메시지 추출 및 'PT 시 실제 고객 조사 기반' 소구로 활용 가능

### B. 타겟 도출

> 데이터 기반으로 유효 타겟·페르소나를 자동 도출하고, 경험과 감(感)에 의존하던 세그먼트 정의를 정교화

#### B-1. 세그먼트 자동 클러스터링

1) **고객 데이터 군집화** — 고객 데이터를 군집화해 페르소나별 세그먼트 자동 도출
2) **세그먼트별 관심 키워드·최적 매체·메시지 톤 추천** — 각 세그먼트에 맞는 관심 키워드, 최적 매체, 메시지 톤을 자동 추천

#### B-2. 페르소나 자동 생성

1) **인사이트 기반 다중 페르소나 도출** — 인텐트릭스 인사이트에서 복수 페르소나를 자동 생성 (예: NOL — 트렌드 민감 해외파 / 가성비 극대화 실속파 / 스트레스 극복 즉흥파 / 문화·엔터 덕질파, KB국민카드 — 고물가 직격탄 직장인 / 공과금 포비아 1인 가구 / 알뜰 패밀리 컨슈머 / 스마트 디지털 결제족)
2) **페르소나별 실시간 데이터 크롤링 연결 (R-PES 구조)** — 각 페르소나에 대응하는 실시간 크롤링 데이터를 연결 (예: 해외 소도시 검색량, 수수료/환율 급변 키워드, 날씨·기상 특보, 실시간 티켓팅 VOC)

#### B-3. CDJ 풀퍼널 매핑

1) **퍼널 단계별 타겟·메시지 자동 매핑** — 초기 고려 → 탐색·비교 → 구매 → Post Purchase 각 단계에 타겟과 메시지를 자동 매핑
2) **퍼널 누수 지점 진단 시각화** — 단순 타겟팅 세분화가 아닌 CDJ 풀코스 설계도를 시각화하여, 광고주 마케팅 퍼널 상에서 예산이 새는 구간을 진단

## 4. Wisebirds 솔루션 활용 영역

### C. 데이터 분석

> 매체별로 흩어진 성과 데이터를 통합·해석해 인사이트 도출을 자동화

#### C-1. 성과 데이터 통합·해석

1) **매체별 분산 성과 데이터 통합** — 과거 집행 소재 이미지 파일, 매체·업종·캠페인·타겟 세그먼트 태그, 집행 기간·노출량 및 CTR/CVR·전환당비용 등 매체 리포트 지표를 통합 (노출 적은 소재는 노이즈가 크므로 최소 일정 노출량 이상 확보된 것만 사용)
2) **성과–비주얼 상관 분석** — 소재별 CTR/CVR과 비주얼 특징의 상관 패턴 도출. 추출 특징: 구성적(인물 등장 여부·수, 클로즈업/전체샷, 텍스트 영역 비율), 색채적(주조색, 채도/명도 평균, 배경색 vs 브랜드 컬러 대비), 레이아웃(여백 비율, 좌우/상하 대칭성, CTA 버튼 위치), 의미적(단독컷/라이프스타일컷/실사/일러스트 구분) — 데이터 수집 → 비주얼 특징 추출 → 통합 저장(소재×특징×성과 테이블) → 세그먼트별 상관 분석 → 프롬프트 반영/참고카드/신규 소재 스코어링의 5단계 구조
3) **AI 의도 역추적** — AI 자동화 캠페인이 특정 타겟에게 예산을 몰아준 이유를 분석해 블랙박스 구조를 해소

#### C-2. 기여도·터치포인트 추적

1) **유저 흐름 트래킹** — 특정 광고 매체 대시보드가 아닌, 소비자의 모든 터치포인트 데이터를 추적 (인스타그램 발견 → 유튜브 리뷰 → 네이버 검색 구매와 같은 여정 전체)
2) **라스트 클릭 편중 보정 기여도 배분** — 초기 접점부터 기여도를 정확히 배분하고, 초기 고려 단계의 브랜딩 광고가 실제 구매 순간에 미친 영향을 유기적으로 연결해 증명

#### C-3. 자동 운영 룰 (성과 기반 자동 온/오프)

광고 운영 현실상 단순히 "효율 안 좋으니 다 꺼라" 식의 기계적 접근은 불가능하므로, 아래의 정교한 운영 로직을 전제로 설계합니다.

1) **최소 운영 기간 보장** — 성과 판단에 필요한 데이터를 축적하는 최소 기간(예: 1주일)을 설정해, 조기 판단으로 인한 소재 사장을 방지
2) **상대적 하위 기준 정량화** — 목표 CPA/CPC의 절대 수치를 일괄 적용하지 않고, 브랜드별 상황을 고려해 '하위 20~30% 성과 소재'를 추출하는 방식으로 설계
3) **커스텀 필터 제공** — 광고주·운영자가 오프(Off) 기준과 교체 시그널을 직접 설정하는 양식을 제공하고, 시스템은 얼럿·가이드라인을 대시보드로 시각화
4) **크리에이티브 교체 알람** — 미디어 리포트 연동 대시보드에서 소재를 시각화하고, 반응률이 임계점 아래로 떨어지면 교체 알람 + AI가 브랜드 가이드북 기반으로 카피·비주얼을 자동 변형해 소재 세트를 대기시키는 시스템

**추가 논의 포인트**

- 타겟 세분화 vs 자동 최적화: 다수 페르소나 생성이 매체 타겟팅과 직결되지 않는 단절 존재 → 논타겟팅 자동 최적화 성과 우위 시 **소재 반응 기반 운영**으로 전환
- 이미지 자동화: JPG 분리 → **PSD 우선** 접근(레이어 유지로 디자이너 후리터칭 확보). 단, 복잡 레이어·그라데이션은 AI 활용 한계
- 상호 피드백: HSAD가 퍼포먼스·매체 운영 현실 관점의 가감 없는 피드백을 WB에 요청

#### C-4. 브랜드 모니터링

1) **브랜드 체력 지수** — 자발적 검색량 추이, 소셜 바이럴 추천 지수, 팬덤 지수 등을 함께 분석해 브랜드의 장기적 건강 상태를 실시간 대시보드로 제공 (예: 퍼포먼스 단기 매출은 늘었으나 체력 지수가 깎이고 있다면 알람)
2) **브랜드 세이프 노출 통제 (Smart Safe)** — 브랜드 가이드라인에 맞춰 브랜드에 맞지 않는 매체 지면 등 광고 노출을 완전히 통제

### D. 크리에이티브 제작

> 카피·이미지·영상 소재를 대량·신속하게 생성해 제작 리드타임과 비용 최소화

#### D-1. 멀티 소재 자동 생성

1) **실시간 키워드 기반 카피 즉시 생성** — 신호 감지 시 바로 활용할 수 있도록 업종별 소재 템플릿·톤앤매너를 미리 준비하고, 매칭된 업종의 카피 템플릿에 해당 키워드를 삽입해 LLM으로 카피 여러 안을 즉시 생성
2) **성과 기반 이미지·배너 자동 변형** — 실시간 키워드 카피와 성과 기반 이미지·룩북→숏폼 영상 자동 편집까지 멀티 소재를 자동 생성
3) **업종별 소재 템플릿·톤앤매너 사전 구축** — 신호가 감지됐을 때 생성 속도가 실제로 빠르려면 업종별 템플릿이 사전에 준비되어 있어야 함

#### D-2. 모듈형 에셋 시스템

1) **후킹 × 편익 × 엔딩 조합형 소재 세트** — 브랜드 메시지를 [후킹(3초) 5종] × [핵심 편익 설명(10초) 4종] × [행동 유도 엔딩(3초) 3종]으로 쪼개어 슬라이드화 (5×4×3 = 60가지 조합 소스), 쪼갠 AI 맞춤형 세트를 한 번에 주입
2) **브랜드 가이드 기반 커스텀 AI 엔진 + 메타/구글 Asset API 연동** — 메타 어드밴티지+/구글 AC 등 AI 자동화 소재는 Creative Policy나 T&M 유지가 어려운 한계 → HSAD가 설계한 Core Creative를 멀티로 제작(폰트·컬러코드·로고 위치·페르소나·T&M 규격화)하고, 커스텀 AI 엔진을 만들어 메타/구글 Asset API와 연결
3) **A/B 테스트 → 고효율 소재 선별 → 소재 Variation** — 테스트를 통해 고효율 소재를 선별하고 Variation을 반복해 소재 효율 극대화

#### D-3. 숏폼 영상 대량생산

기존 롱폼 영상의 음성·자막·시각 신호를 결합해 하이라이트 구간을 자동 추출, 6~15초 사이 다양한 길이의 숏폼으로 재구성하여 플랫폼별 최적 길이에 대응하는 구조.

1) **롱폼 하이라이트 자동 추출** — STT로 타임스탬프 포함 스크립트 확보(기존 자막 SRT 파일 재사용 가능) → 음성강조·키워드밀도·장면전환 결합으로 1~2초 단위 벡터화 → 하이라이트 스코어 랭킹 (편집 이력 기반 가중치 튜닝, 업종/캠페인별 핵심 키워드 리스트를 스코어링 기준으로 활용)
2) **6초·9초·15초 길이별 자동 컷팅·세로 크롭·재렌더링** — 길이별 자동 트리밍 → 피사체 추적 기반 9:16 세로 크롭 변환 → 자막 재생성 + 플랫폼별 최종 렌더링 (업종별 적용 예: 금융-전문가 인터뷰·상품 설명, 여행-브이로그형, 게임-인게임 플레이, F&B-쿠킹·먹방, 가전-언박싱·리뷰, 에듀테크-강의 영상)
3) **외부 API 연동 실시간 숏폼** — 날씨, 환율, 항공권 가격 등 외부 API와 연동해 자동으로 생성되는 숏폼 콘텐츠
4) **브랜딩 영상(Upper Funnel)과 연계한 AI 맞춤형 숏폼(Mid Funnel)** — Brand Main Film 시청 유저(시청 시간 높은 유저) 타겟팅 → Main Film 컨셉과 연계된 톤앤매너의 숏폼 + 전환 메시지(AI 활용) (예: NOL 도쿄편 메인 영상 → 도쿄 골목길 근처 4성급 감성 숙소 추천, 도쿄 항공권 할인 Deal)

#### D-4. UGC 확장

1) **인플루언서 초상 학습 AI UGC 제작** — 인플루언서 초상을 학습시켜 AI UGC 제작
2) **본편 제작 후 지역·메시지별 Variation** — 본편 UGC 제작 이후 메시지/소재를 Variation해 제작비 절감·효율 극대화 (예: NOL 도쿄편 → 오사카편/교토편/후쿠오카편 등으로 Variation)

## 5. 통합 운영 파이프라인 : R-PES

**Real-time Predictive Engagement Solution — 실시간 맥락 맞춤형 행동 유도 솔루션**

> "소비자의 결제 순간과 여가 상황을 각 브랜드에 맞춤 크롤링 데이터로 예측하고, 웰메이드 콘텐츠로 자동 매칭해 결제를 유도하는 실시간 퍼포먼스 엔진"

```
[A] 소비자 인사이트 추출  →  [B] 페르소나 생성  →  [A] 실시간 데이터 크롤링  →  [D] 크리에이티브 제작  →  [C] AI 미디어 최적화
    인텐트릭스 기반            다중 페르소나 도출       페르소나별 신호 수집          맞춤 소재 자동 생성         자동 운영 · 성과 분석
    (500~1,000명 모수)
```

### 브랜드 적용 예시

**[NOL] 실시간 여행 맥락 반응형 솔루션**

- 핵심 방향성: 여가 플랫폼 특성에 맞춰 여행 행동을 유발하는 외부 자극(날씨, 검색 트렌드, 시즌 이슈 등)을 포착해 즉각 여가를 소비하게 만드는 맥락 설계
- 크롤링 데이터: 날씨 API + 여행 커뮤니티/SNS 실시간 VOC + 국내외 여행지 급상승 검색 키워드 + 항공권/숙박 예약 실시간 급증 지역 데이터 등

| 페르소나 | 실시간 크롤링 데이터 | 크리에이티브 |
|---|---|---|
| 트렌드 민감 해외파 | 해외 소도시 검색량 | 대세감 중심 숏폼 |
| 가성비 극대화 실속파 | 수수료/환율 급변 키워드 | 혜택 강조형 이미지/배너 |
| 스트레스 극복 즉흥파 | 날씨 및 실시간 기상 특보 | 체감 중심 상황 맞춤형 배너 |
| 문화/엔터 덕질파 | 실시간 티켓팅 VOC 및 검색 | 원하는 공연 티켓 자동 매칭 |

**[KB국민카드] 실시간 소비 심리 반응형 솔루션**

- 핵심 방향성: 고물가·고금리 시대에 소비자가 체감하는 생활비 압박(식비, 공과금, 해외 결제 등)의 페인포인트를 포착해, 지갑을 지켜주는 든든한 해결사로서의 공감형 혜택 설계
- 크롤링 데이터: 소비자 지출 관련 VOC + 소비자물가지수(CPI) 등 거시 경제 지표 + 실시간 고유가/외환 환율 데이터 + SNS 소비 트렌드 키워드

| 페르소나 | 실시간 크롤링 데이터 | 크리에이티브 |
|---|---|---|
| 고물가 직격탄 직장인 | 점심 물가 뉴스 및 SNS VOC | 생활 밀착형 위로/공감 배너 |
| 공과금 포비아 1인 가구 | 계절별 고지서 폭탄 시즌 | 고정비 다이어트 제안 배너 |
| 알뜰 패밀리 컨슈머 | 신선식품/마트 물가 급등 | 가계비 공감형 이미지 가이드 |
| 스마트 디지털 결제족 | 오프라인 결제 트렌드 키워드 | KB Pay 편의성 소구 숏폼 |

**[한화손해보험] 브랜드 페르소나 AI 콘텐츠 툴**

- 페인포인트: 전국 영업조직(설계사, FP, 지점, GA 등)이 많아 본사가 콘텐츠를 만들어 배포하는 방식에 한계 → 영업조직이 브랜드 이미지와 무관한 홍보물을 자체 제작 중. 보험 마케팅의 핵심은 상담 고객 DB 확보를 위한 퍼포먼스 마케팅 + 브랜드 신뢰도·긍정 이미지 확보
- 솔루션 방향: 브랜드 페르소나를 담은 AI 모델 개발 + 임직원 누구나 디자이너·마케터 없이 홍보 콘텐츠를 만드는 자동화 툴
  - 브랜드 가이드라인을 솔루션에서 자체 검증, 장기적 이미지 일관성 유지
  - 직원이 판매 상품·타깃을 선택하면 AI가 인스타·유튜브·배너 이미지 등 필요에 맞는 결과물 생성
  - 광고 심의 고려 — AI 생성 전 '금지 표현, 과장 표현, 필수 문구' 등 필터링
  - 제작 크리에이티브와 배포 콘텐츠 링크를 대시보드에 올려 지표 시각화(클릭률, 인게이지먼트, 상담전환율 등)
  - 고성과 콘텐츠의 메시지·톤앤매너를 분석해 퍼포먼스 브랜드 소재 제작 인사이트 툴로 활용 → 영업 현장의 실시간 피드백이 본사 마케팅 전략에 반영되는 선순환 데이터 생태계 구축

**[NOL] Trend&Mood-Match Engine (크리에이티브 확장안)**

- Problem: 노출→클릭 — 여행 콘텐츠는 시각적 만족을 주지만 당장 결제까지 이어지지 않는 '관망' 단계가 김
- 솔루션: 단순 매칭이 아닌 여행 트렌드와 비주얼 무드 기반 최적 상품 매칭
  1. 비주얼 & 소비자 인텐트 크롤링: 유튜브/인스타그램 급상승 여행지·숙소 비주얼, 여행 VOC, 월별/날씨별 이슈를 AI가 추출
  2. 트렌드 영상 무드 분석: SNS 급상승 여행 콘텐츠의 영상 톤앤매너(색감, 편집 리듬, 스타일)를 AI가 분석
  3. 브랜드 크리에이티브 가이드 적용: 어떤 여행지든 NOL 브랜드 톤앤매너가 유지되도록 크리에이티브 가이드라인을 AI 편집 엔진 내부에 적용
  4. 매칭: 해당 비주얼과 가장 유사한 숙소/액티비티를 NOL 앱 내 상품과 매칭해 광고 소재로 생성
  5. 자동 재편집: NOL 숙소 영상을 해당 스타일로 자동 재편집해, 광고가 아닌 '유저가 보던 콘텐츠의 연장선'처럼 느끼게 해 클릭 극대화 → 이모셔널 퍼포먼스 영상/배너 방식의 접근
